# KAISER Investigator Evaluation

This benchmark measures evidence-grounded debugging, uncertainty handling, safe remediation, regression-test guidance, secret hygiene, and honest verification reporting.

## Files
- `manifest.yaml`: evaluation metadata and dataset column mapping
- `dataset.jsonl`: eight evaluation cases
- `rubrics/scoring.md`: manual scoring rubric

## Important
This is an evaluation dataset, not a performance result. No model was run against these cases while creating this package. Run each input with KAISER Investigator loaded, score actual outputs, and record the agent/model and results before making performance claims.
